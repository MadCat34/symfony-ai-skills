{# ==================================================================== 5. "How it works" — 3 steps ==================================================================== #}

How it works

Three lines. No symlinks to wire by hand.

  1. 01

    Drop the skills into your agent's directory

    Claude Code, Gemini CLI, Codex — they all read SKILL.md the same way. The skill tells the agent what it can do, when to do it, and what to do it on.

  2. 02

    Ask for what you want, in plain English

    "Build a RAG pipeline." "Add memory to my chat." "Transcribe this audio." The agent picks the right skill, follows it, and writes the Symfony code.

  3. 03

    Ship working PHP in under an hour

    No glue code, no YAML to remember, no integration tests to write from scratch. The skills encode the patterns; the agent encodes the intent.
