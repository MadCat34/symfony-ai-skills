FAQ

Questions

Is this an official Symfony project?

No. It is an independent, MIT-licensed project that documents the open-source symfony/ai components.

Which version of Symfony AI does it cover?

symfony/ai 0.15. Symfony AI is experimental and breaks between minor versions, so each skills release targets one symfony/ai line.

Do I need an API key or an MCP server?

No. The skills are Markdown files that your coding agent reads when a question needs them. Nothing runs in your application.

Which agents are supported?

Claude Code (plugin), Gemini CLI (extension), OpenAI Codex, GitHub Copilot, Kilo Code, OpenCode, and any agent that reads agentskills.io skills from a directory.
